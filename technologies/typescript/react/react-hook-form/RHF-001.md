# RHF-001 — Use React Hook Form for non-trivial forms

**Status:** Accepted

## Rule

Use React Hook Form when a form has meaningful validation, multiple related fields, dynamic fields, submission state, or reusable form logic.

## Agent behavior

For non-trivial forms, prefer the form abstraction over manually coordinating separate values for each field, error, dirty flag, and submission condition.

## Exceptions and trade-offs

A tiny form with one or two simple inputs may be clearer without an additional abstraction.
