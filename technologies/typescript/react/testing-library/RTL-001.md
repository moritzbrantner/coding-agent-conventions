# RTL-001 — Test observable user behavior

**Status:** Accepted

## Rule

Test interactions and observable UI outcomes rather than React implementation details.

## Agent behavior

Interact through user-facing controls and assert visible or accessible results. Avoid assertions against private component state, internal hook calls, or incidental component structure.

## Rationale

Behavior-focused tests remain valuable through implementation refactors.

## Exceptions and trade-offs

Pure utilities and hooks may be tested through their direct API when that API is the unit's observable contract.
