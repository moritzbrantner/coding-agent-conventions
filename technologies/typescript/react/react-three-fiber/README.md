# React Three Fiber conventions

React Three Fiber is treated as a React specialization and inherits the TypeScript and React conventions by path. Because it also adapts Three.js, use the [React Three Fiber profile](../../../../profiles/react-three-fiber.md) to compose this branch with the independent [Three.js branch](../../threejs/).
