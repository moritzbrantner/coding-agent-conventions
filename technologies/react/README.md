# React conventions

Rules in this directory use the `REACT-*` prefix and apply to React-specific component, state, rendering, hook, effect, and composition behavior.

A rule that is fundamentally about TypeScript belongs under `technologies/typescript/`. React rules should add React-specific constraints instead of copying broader language rules.

When React is used with TypeScript, both convention families apply. More specific rules take precedence according to `REPO-002`.
